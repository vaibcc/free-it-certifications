# Free IT Certifications

A curated directory of free IT courses, learning paths and professional credential opportunities from official technology providers.

**Live website:** https://vaibcc.github.io/free-it-certifications/

## What this project covers

- Cybersecurity
- Networking
- Cloud computing
- IT support
- Linux and systems administration
- Programming and development
- DevOps and containers
- Data and databases

## Accuracy comes first

The project deliberately distinguishes between:

1. **Free learning + free credential** — both the learning and the stated completion credential are free.
2. **Free learning + paid or conditional credential** — course content may be free, but an exam, subscription, assessment or formal certification may cost extra.
3. **Paid assessment or credential** — preparation resources may be free, but the credential itself is paid.

A free course is not automatically a free certification. Promotions, exam vouchers and free trials can expire or vary by country. Always confirm current terms on the official provider website.

## Project files

- `index.html` — responsive website and searchable directory interface.
- `courses.json` — structured catalogue of learning resources.
- `robots.txt` — crawler instructions.
- `sitemap.xml` — search engine sitemap.
- `llms.txt` — concise information for AI assistants and discovery tools.

## Contributing

Please suggest resources only when they have an official provider page. Include the provider, category, level, direct URL, what is free, whether a credential is included, and any exam or subscription costs. Do not label a resource as a free certification without checking the current provider terms.
